# AgroConnect Ghana: A/B Testing Analysis

## Overview

A data analysis project using data from approximately 3,000 farmers to evaluate whether voice-note communication improves agricultural outcomes.

## Objective

To determine whether voice-note communication increases crop yield and whether higher yields translate into improved profitability.

## Tools

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Statistical Analysis

## Approach

* Data cleaning
* Exploratory Data Analysis
* Treatment vs. control group comparison
* Statistical analysis
* Profitability analysis
* Business recommendations

## Key Finding

Farmers exposed to voice-note communication achieved approximately **4.2% higher crop yields**.

However, higher yields did not necessarily result in higher net profit due to increased farming costs.

## Business Impact

The findings suggest that improving productivity alone is not enough; agricultural interventions should also consider production costs and farmer profitability.

## Recommendations

* Gradually Deploy whatsapp voice Notes due to proven yield success
* Optimise for ROI - Refine advisory content to recommend lower-cost, high-impact inputs.
* Prioritize Ashanti and Northern regions for initial full-scale launch
